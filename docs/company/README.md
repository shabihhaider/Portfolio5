## Quick Reference

**New project checklist (in order):**
1. Send client questionnaire → [onboarding-checklist.md](./onboarding-checklist.md)
2. Write SOW → [scope-of-work.md](./scope-of-work.md)
3. Quote correctly → [pricing-policy.md](./pricing-policy.md)
4. Get agreement confirmed → [client-agreement.md](./client-agreement.md)
5. Collect 50% deposit → don't start without it
6. Deliver → [delivery-handoff.md](./delivery-handoff.md)
7. Collect final payment → hand over credentials
8. Offer retainer → [maintenance-retainer.md](./maintenance-retainer.md)
